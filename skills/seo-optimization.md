# SEO 内容优化指南

## 关键词策略

### 金字塔模型
1. **核心词**（1个）：高搜索量、高竞争（如 "Python教程"）
2. **长尾词**（3-5个）：中搜索量、中竞争（如 "Python入门教程零基础"）
3. **问题词**（5-10个）：低搜索量、低竞争（如 "Python适合初学者吗"）

### 关键词密度
- 主关键词: 1-2% 密度
- H1 必须包含主关键词
- 前 100 字内出现主关键词
- 自然分布，不要堆砌

## 内容结构

```markdown
# H1: 包含主关键词（50-60字符）

## H2: 二级主题 1
段落包含长尾关键词...

## H2: 二级主题 2
...

## H2: FAQ
### Q: 包含问题词？
A: 简洁回答...
```

## Meta 标签

```html
<title>主标题 | 品牌名（50-60字符）</title>
<meta name="description" content="150-160字符的吸引点击描述">
<meta name="keywords" content="关键词1, 关键词2">
```

## 检查清单

- [ ] 移动端适配（responsive）
- [ ] 页面加载速度 < 3s
- [ ] 图片有 alt 标签
- [ ] URL 简短且含关键词
- [ ] 内链 3-5 条指向相关内容
- [ ] 外部链接 1-2 条指向权威来源
- [ ] 结构化数据（Schema.org）标记
