# 联网深度研究流程

## 核心原则

> 不猜测，不编造。先搜索 → 再验证 → 最后总结。

## 研究步骤

### Step 1: 解析问题 → 提取搜索关键词

从用户问题中提取 2-3 组搜索关键词：
- **核心词**: 问题主体（中英文各一版）
- **验证词**: 用来交叉验证的信息关键词

示例：
- "AI视频生成公司有哪些" → `top AI video generation companies 2025` + `AI视频生成创业公司`
- "Python FastAPI vs Flask 性能对比" → `FastAPI vs Flask benchmark 2025` + `FastAPI Flask 性能测试`

### Step 2: 多源搜索（至少 2 个来源）

使用 OpenClaw 打开 Google 搜索：
1. **英文搜索**: `https://www.google.com/search?q=<关键词>` → 提取前 10 条结果的标题+摘要
2. **中文搜索**: `https://www.google.com/search?q=<中文关键词>` → 提取前 10 条结果
3. 对于关键信息，打开 2-3 个具体页面抓取详细内容

### Step 3: 信息验证（交叉引用）

对每条关键事实：
- [ ] 是否有 2 个以上独立来源确认？
- [ ] 来源是否可靠（官方/权威媒体/学术）？
- [ ] 信息是否有时效性（搜索时加年份）？
- [ ] 是否有相反观点需要呈现？

无法验证的信息 → 标注"待验证"

### Step 4: 深度分析

不只是罗列搜索结果，要做：
- **分类归纳**: 按主题/类别/时间线分组
- **对比分析**: 不同来源的异同
- **趋势判断**: 从多源信息中提炼趋势
- **局限说明**: 坦诚说明哪些信息找不到或不确定

### Step 5: 输出格式

```markdown
## 研究主题: [用户问题]

### 关键发现
- 发现 1（来源: [链接]）
- 发现 2（来源: [链接]）

### 详细分析
[分类归纳的信息]

### 数据/事实
| 事实 | 来源 | 可靠性 |
|------|------|--------|
| ... | [链接] | 高/中/待验证 |

### 不同观点
- 观点 A: ...（来源: ...）
- 观点 B: ...（来源: ...）

### 局限与说明
- 未找到 XXX 相关信息
- YYY 数据可能不是最新

### 结论
[一句话总结]

### 参考资料
1. [来源标题](URL)
2. [来源标题](URL)
```

## 搜索技巧

### Google 高级搜索
```
"精确匹配" — 搜索精确短语
site:example.com — 限定网站
-after:2024 — 指定时间后
filetype:pdf — 文件类型
intitle:关键词 — 标题包含
-排除词 — 排除无关结果
```

### 中文资料搜索
- 知乎/公众号 → 用 `site:zhihu.com`
- 行业报告 → 加 `行业报告|白皮书|研报`
- GitHub → `site:github.com`
- 学术 → `site:arxiv.org` 或 `scholar.google.com`

### 时效性信号
- 加当年年份: `Python web framework 2025`
- 加 "latest" / "new" / "recent"
- 查 GitHub 看最近更新时间

## 对本地 LLM 的特殊说明

如果本地 LLM 训练数据截止日期较早（如 2024 年前），请务必：
1. **不要依赖训练记忆回答时效性问题** — 先搜索再回答
2. **涉及"最新""最近""今年"的问题** — 必须在回答中注明搜索日期
3. **涉及具体数字/统计数据** — 必须给出来源，不可编造
4. **涉及公司/产品动态** — 优先查看官网和官方公告
