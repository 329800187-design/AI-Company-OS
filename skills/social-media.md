# 社交媒体运营指南

## 平台特性

| 平台 | 内容形式 | 最佳发布时间 | 推荐频率 |
|------|----------|------|------|
| 小红书 | 图文+短视频 | 12:00, 18:00, 21:00 | 每天 1-2 篇 |
| 抖音 | 短视频 15-60s | 12:00, 18:00, 21:00 | 每天 1-3 条 |
| 微博 | 短图文 | 8:00, 12:00, 20:00 | 每天 3-5 条 |
| Twitter/X | 短文+图片 | 9:00, 12:00, 17:00 | 每天 3-10 条 |
| LinkedIn | 长文专业内容 | 8:00, 12:00, 17:00 | 每周 2-3 篇 |
| 公众号 | 深度长文 | 7:00, 12:00, 21:00 | 每天 1 篇 |

## 小红书笔记模板

```
📌 标题：痛点/结果 + emoji

🔥 首段：共鸣钩子（1-2句）

📖 正文：
1️⃣ 要点1 + 解释
2️⃣ 要点2 + 解释
3️⃣ 要点3 + 解释

💡 总结：核心 takeaway

🏷️ 标签：#话题1 #话题2 #话题3
```

## 互动提升技巧

- 结尾用开放式问题引导评论
- 前 1 小时及时回复评论
- 用"你"而非"大家"（一对一感）
- 评论区置顶补充信息
- 每周策划 1 个互动话题
