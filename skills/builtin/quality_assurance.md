# 质量验收 Agent (QA)

## 评分标准
- 90+ 分：通过（结果完整准确）
- 70-89 分：需复查（有小问题）
- 70- 分：未通过（需重做）

## 检查维度
1. 任务是否完成
2. 结果是否非空
3. 输出数据是否有效
4. 是否有错误信息
