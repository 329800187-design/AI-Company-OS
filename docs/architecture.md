# AI Company OS — 系统架构总览（V1）

## 一、项目本质

这不是一个"AI 工具集合"或"聊天机器人"——这是一个**AI 多智能体操作系统（AI OS）**，一个可以自动执行任务的虚拟 AI 公司。

## 二、架构分层（7层）

```
┌──────────────────────────────────────┐
│  1️⃣ 用户层（User Layer）              │
│  ───────────────────────────────────  │
│  个体创业者 · 电商卖家 · 内容创作者 · 小团队 │
│  输入：自然语言目标                      │
│  "帮我做个网站 / 生成小红书内容 / 分析竞品" │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│  2️⃣ 大脑层（Brain Layer）              │
│  ───────────────────────────────────  │
│  CEO Agent（唯一主脑）                 │
│  ├ 理解用户意图 → 拆解任务              │
│  ├ 分配执行Agent                       │
│  ├ 决策是否重做                        │
│  └ 汇总结果 → 输出任务列表              │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│  3️⃣ 执行层（Worker Agents）            │
│  ───────────────────────────────────  │
│  ✅ 现有：                             │
│  ├ CEO Agent（规划）→ 仓库根目录        │
│  ├ QA Agent（验收）→ agents/qa_agent/  │
│  ├ Codex Agent（代码）→ agents/codex_agent/ │
│  ├ OpenClaw Agent（浏览器）→ openclaw_agent/ │
│  ├ System Agent（系统操作）→ agents/system_agent/ │
│  │                                       │
│  🔜 待扩展：                            │
│  ├ Image Agent（图片生成）               │
│  ├ Video Agent（视频生成）               │
│  ├ Data Agent（数据处理）                │
│  └ Marketing Agent（内容营销）           │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│  4️⃣ 调度层（Workflow Engine）           │
│  ───────────────────────────────────  │
│  workflow_router → task_router → agent_router │
│  🔜 未来→ LangGraph / 自定义DAG        │
│  功能：任务流控制 · 执行顺序 · 重试 · 分支 │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│  5️⃣ 任务层（Task System）              │
│  ───────────────────────────────────  │
│  Task { goal, assigned_to, status,    │
│         input, output, score }        │
│  状态流：todo → doing → review → done │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│  6️⃣ 反馈层（QA System）                │
│  ───────────────────────────────────  │
│  QA Agent：评分 · 检查输出 · 触发重试   │
└──────────────────┬───────────────────┘
                   ▼
┌──────────────────────────────────────┐
│  7️⃣ 数据层（Data Layer）               │
│  ───────────────────────────────────  │
│  ✅ SQLite（当前）                     │
│  🔜 PostgreSQL + Redis + Vector DB   │
└──────────────────────────────────────┘
```

## 三、商业定位

### 产品定位
> 不是"AI 系统"——卖的是 **AI 员工 / AI 团队 / AI 外包能力**

### 目标客户
| 客户类型 | 痛点 | 需求 |
|---------|------|------|
| 个体创业者 | 不会技术、没团队 | 自动做网站、写内容、处理客户 |
| 电商卖家 | 效率低 | 商品描述、主图文案、广告素材、客服 |
| 内容创作者 | 生产力瓶颈 | 脚本、视频、标题、封面 |
| 小团队 | 人力不足 | 自动化运营、数据处理、营销执行 |

## 四、当前难点

1. **Agent 协同** — 多 Agent 输出格式不统一、任务无法衔接、状态不同步
2. **任务调度** — 从手动 API 调用 → 自动流转系统（异步、重试、并发）
3. **记忆系统** — Agent 当前"失忆"，需持久化记忆能力
4. **安全沙箱** — Codex/System Agent 需权限控制 + sandbox + review
5. **性能** — Agent 调用链长、响应慢、重复计算
6. **产品化** — 工程能跑 ≠ 用户愿意用（UI、一键操作、模板、场景化）

## 五、开发路线图

```
阶段1（已完成 ── 跑通闭环）
├ Task 系统（SQLite 持久化）
├ CEO Agent（AI 拆解 + 规则降级）
├ QA Agent（评分验收 + 重试）
├ Codex Agent（沙箱执行）
├ OpenClaw Agent（浏览器自动化）
├ System Agent（系统操作）
├ AI Registry（本地 AI 资源发现）
├ Commander（主脑循环执行）
├ 配置中心（多 Provider 切换）
├ Docker 部署
└ 全中文 Web UI（7 Agent 页面 + 总控台）

阶段2（下一步 ── 真正的自动化）
├ 异步任务队列（Commander 不卡 UI）
├ Workflow 自动流转（DAG）
├ Image / Video Agent
├ Memory 系统

阶段3（中期 ── 可持续运行）
├ PostgreSQL / Redis
├ 权限与 API Key 鉴权
├ 结构化日志与监控
├ WebSocket 实时推送

阶段4（产品化 ── 可以卖）
├ 精美 UI（非 Swagger）
├ 行业模板（电商/内容/开发）
├ 一键安装包
├ 多租户
└ 定价体系
```
