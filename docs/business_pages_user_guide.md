# 业务页面使用说明

> 适用版本：AI Company OS v1.5.0（2026-07-06）

## 概述

AI Company OS 提供五个业务页面和一个交付中心，构成完整的内容生产闭环：

```
业务页面输入 → Agent 生成 → 结构化展示 → 保存到交付中心 → Delivery 搜索/预览/下载
```

## 五个业务页

### 1. Marketing（写文案）

**入口**：左侧导航「常用功能 → 写文案」或首页卡片「写文案」

**支持 7 种模式**：

| 模式 | 说明 |
|------|------|
| 通用文案 | 适用于各类推广文案 |
| 小红书 | 平台风格适配 |
| 抖音 | 短视频脚本文案 |
| SEO 长文 | 搜索引擎优化文章 |
| 邮件营销 | EDM 邮件内容 |
| 品牌策略 | 品牌定位与传播方案 |
| 活动方案 | 线上/线下活动策划 |

**使用步骤**：
1. 选择文案类型
2. 填写需求描述（如"帮我写一条朋友圈文案，推广手工耳环"）
3. 点击「生成」
4. 查看结构化结果（标题、正文、标签等）
5. 点击「复制」可复制内容
6. 点击「保存到交付中心」归档

### 2. Image（做图片）

**入口**：左侧导航「常用功能 → 做图片」或首页卡片「做图片」

**产出内容**：图片生成提示词（prompt）、负面提示词、风格、构图、光线、配色等视觉 brief。

**注意**：当前版本产出的是图片提示词框架，不直接生成真实图片。

### 3. Data（看数据）

**入口**：左侧导航「常用功能 → 看数据」或首页卡片「看数据」

**产出内容**：数据分析报告框架，包括关键指标、趋势分析、发现、风险、建议等。

### 4. Research（做调研）

**入口**：左侧导航「常用功能 → 做调研」或首页卡片「做调研」

**产出内容**：结构化研究简报，包括市场概况、关键发现、竞品分析、机会、风险、建议行动等。

### 5. Website（建网站）

**入口**：左侧导航「常用功能 → 建网站」或首页卡片「建网站」

**产出内容**：落地页文案方案，包括页面目标、目标受众、Hero 区、各板块内容、CTA、信任元素、SEO 建议等。

## 交付中心（Delivery）

**入口**：左侧导航「常用功能 → 交付中心」

### 功能

| 功能 | 说明 |
|------|------|
| 列表 | 查看所有已保存的交付物 |
| 搜索 | 按 task_id 或关键词搜索 |
| 预览 | 查看 Markdown 格式的交付内容 |
| 详情 | 查看完整交付详情 |
| 下载 | 下载交付物文件 |

### 从业务页保存到交付中心

1. 在任意业务页生成结果后
2. 点击「保存到交付中心」按钮
3. 系统自动保存，返回 task_id
4. 打开「交付中心」即可看到新记录

### 在交付中心查找内容

1. 打开「交付中心」页面
2. 在搜索框输入 task_id（如 `agent_70897dbc4433`）
3. 点击搜索结果卡片查看详情
4. 点击「预览」查看 Markdown 内容
5. 点击「下载」保存到本地

## 常见问题

### Q: 生成结果没有出现？

检查后端是否运行在 `localhost:8000`，Vite dev server 是否运行在 `localhost:5173`。

### Q: 保存到交付中心失败？

确认 Vite 已代理 `/minidelivery` 路径（当前配置已包含）。如仍有问题，重启后端和 Vite。

### Q: 交付中心列表为空？

确认后端已重启。旧进程可能导致路径问题。

### Q: 使用的是哪个端点？

业务页统一使用 `/agents/{agent_id}/execute` 端点。旧端点 `/agents/{agent_id}/run` 仍存在但不推荐使用。
